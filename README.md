# 모퉁이 카페 주문 앱

메뉴를 고르고 옵션을 선택해 주문하는 고객 화면과 주문 상태·재고를 관리하는 관리자 화면을 제공하는 브라우저 앱입니다. HTML, CSS, 순수 JavaScript로 만들었으며 주문과 재고 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행 방법

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 별도의 설치, 빌드 도구, 프레임워크, 외부 JavaScript 라이브러리는 필요하지 않습니다. 브라우저에서 로컬 파일 실행이 제한되면 저장소 루트에서 간단한 정적 웹 서버를 실행해 접속할 수 있습니다.

## 사용법

### 고객 주문

1. **메뉴 주문** 탭에서 메뉴 이름, 가격, 재고를 확인합니다.
2. 원하는 메뉴에서 샷 추가(+500원) 또는 시럽 추가(+0원)를 선택하고 **담기 +**를 누릅니다.
3. 주문 바구니에서 수량을 조절하거나 항목을 삭제하고 합계를 확인합니다.
4. **주문하기**를 누릅니다. 메뉴별 요청량이 재고를 넘으면 주문 전체가 접수되지 않습니다.

### 관리자

1. **관리자** 탭에서 주문과 현재 재고를 확인합니다.
2. 접수 상태의 주문에서 **제조 완료 처리**를 눌러 상태를 변경합니다.
3. 재고는 고객 주문 접수 시 차감되며 완료 처리에서는 다시 차감되지 않습니다.

## 저장 데이터

메뉴와 재고는 `cornerCafe.menu.v1`, 주문은 `cornerCafe.orders.v1` 키에 저장됩니다. 처음 실행하면 메뉴 5종과 초기 재고, 빈 주문 목록이 생성됩니다. 각 저장 데이터가 이미 있으면 초기값으로 덮어쓰지 않습니다. 이 앱은 브라우저 단위 시연용이며 다른 기기와 데이터를 공유하거나 결제를 처리하지 않습니다.

## 수동 검증 시나리오

1. 처음 열었을 때 메뉴 5종과 가격·재고, 빈 장바구니가 나타나는지 확인합니다.
2. 아메리카노에 샷을 추가해 담고 옵션 추가 금액이 500원, 시럽만 추가한 메뉴의 옵션 추가 금액은 0원인지 확인합니다.
3. 수량 +/−, 삭제를 조작해 항목 금액과 총액이 바뀌는지 확인합니다.
4. 재고가 1개 남은 메뉴를 2개 이상 요청해 주문을 막는지 확인합니다. 메뉴 재고가 충분한 주문은 접수되고 재고가 요청 수량만큼 줄어드는지 확인합니다.
5. 마지막 재고까지 주문하면 메뉴와 관리자 재고 목록에 품절이 나타나는지 확인합니다.
6. 관리자 탭에서 주문 내용, 옵션, 금액, 접수 상태가 보이는지 확인하고 제조 완료 처리를 눌러 상태가 바뀌는지 확인합니다.
7. 새로고침한 뒤 주문 상태와 재고가 유지되는지 확인합니다.
8. 모바일 폭(예: 375px)과 데스크톱 폭에서 메뉴, 장바구니, 탭 및 관리자 목록이 겹치거나 가로로 넘치지 않는지 확인합니다.
